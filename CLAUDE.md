# Project Instructions

## Overview

ViperTech LLC is a React + Vite ecommerce frontend for computer accessories and technology products. It uses local mock product data and browser localStorage for cart and wishlist state. There is no backend, authentication, or real payment processing.

## Commands

- `npm.cmd run dev` - start the local development server
- `npm.cmd run build` - create the production build

## Frontend Scope

- Keep the existing ViperTech visual system: midnight navy, electric cyan, blue accents, and light shopping surfaces.
- Preserve the responsive routes and frontend-only checkout flow in `src/App.jsx`.
- Keep product data replaceable with a future API; do not add a backend unless explicitly requested.

## Working Guidelines

- Inspect the repository before making changes.
- Keep changes focused and minimal.
- Prefer existing tools and conventions when they are introduced.
- Run relevant validation after edits.
- Do not commit changes unless explicitly requested.
